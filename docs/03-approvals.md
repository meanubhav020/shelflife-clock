# Approvals

[REF-APR-01] Any action other than MONITOR on a HEALTHCARE product requires QA Lead approval before it is carried out.

[REF-APR-02] Any action other than MONITOR on a batch with value above 2,000 requires Regional Manager approval. Above 10,000 it requires Finance Director approval instead.

[REF-APR-03] DISPOSE always requires Finance approval, whatever the value or class.

[REF-APR-04] No action other than MONITOR may be released for a batch whose trust flag is not OK. Such batches go to Inventory Control for correction.

[REF-APR-05] An action that triggers none of REF-APR-01 to REF-APR-04 may be released without a human.
